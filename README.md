🎵 Music Player

A simple desktop Music Player built with Python, Tkinter, and Pygame. This application provides an easy-to-use graphical interface for playing audio files and managing a playlist.

Features

- 🎵 Load multiple MP3 and WAV files
- ▶️ Play songs
- ⏸️ Pause and resume playback
- ⏹️ Stop music
- ⏮️ Play the previous song
- ⏭️ Play the next song
- ➕ Add songs to the playlist
- ❌ Delete songs from the playlist
- 🖥️ Simple and user-friendly GUI

Technologies Used

- Python
- Tkinter
- Pygame

Requirements

Install the required package:

pip install pygame

How to Run

1. Clone the repository:
   
   git clone https://github.com/sachinsachin882/MusicPlayer.git

2. Navigate to the project folder:
   
   cd Music-Player

3. Run the application:
   
   python music_player.py
